FILES INCLUDED IN THIS ZIP:
1. index.html — The complete interactive 40-Day Hadith Tracker web app.
2. 40-Days-Teleprompter-Scripts.txt — All 40 daily YouTube/Instagram scripts.
3. Printable-40-Hadith-Checklist.html — Printable 40-Day tracker table.

HOW TO USE COMPLETELY OFFLINE:
- Extract this ZIP folder anywhere on your computer, tablet, or phone.
- Double-click `index.html` to open it in any browser (Chrome, Edge, Safari, Brave).
- No internet connection is required. When offline, the app automatically uses
  your device's built-in Offline Male Voice Engine for Arabic & English.
- To save your progress while offline, click the 'Offline .ZIP' button in the
  top bar and click 'Save Backup (.json)', or load it anytime via 'Load Backup'.

TIP FOR BEST OFFLINE MALE VOICES:
- Windows: Settings -> Time & Language -> Speech -> Add 'Arabic (Saudi Arabia)'
  (Naayf Male) and 'English (United Kingdom / US)' (Ryan / Guy / George Male).
- macOS / iOS: System Settings -> Accessibility -> Spoken Content -> System Voice
  -> Download 'Maged' or 'Tarik' (Arabic Male) and 'Daniel' or 'Alex' (English Male).
